# 追放王子とメイドちゃん

町の育成と横スクロール自動遠征を組み合わせるゲームの試作。

**[iPhone / ブラウザで遊ぶ（HTML試作）](https://cp-base.github.io/exiled-prince-and-maid/)**

現在のv0.3試作では、メイドの提案を選び、二人で自動遠征し、装備を発見して帰還後に付け替えられます。街道と工房を育成し、灰渡のマップ目標に挑戦できます。各種数値・イベント・装備・町の育成項目は未確定の仮実装です。
