# スモークテスト案内

このリポジトリの試作版は仕様変更を伴いながら進んでいます。テストの対象は次のとおりです。

- `node tests/v010_final_showdown.cjs` — **現在のv0.10向け**。4体目救出、トーマの進行表示、決戦解放・ボス・敗北後再挑戦・決戦勝利クリア・クリア後継続。
- `node tests/v08_economy_rumor_speed.cjs` — v0.10でも回帰実行（商人・戦利品・1/4倍速）。

- `node tests/v09_village_relations.cjs` — **v0.9の履歴テスト**。旧「討伐依頼を選び8体目に大狼」といった現在廃止した条件を含む。


- `node tests/v07_heroine_flow.cjs` — **v0.7の履歴テスト**。旧「10体目救出」を前提とする。
- `tests/v04_smoke.cjs` / `v05_heroine_smoke.cjs` / `v06_loot_party_combat.cjs` — **履歴テスト**。過去の確定装備ドロップや確定ボス装備を前提にするため、v0.8では期待どおり動かない箇所がある。元バージョンのコードで実行するため残す。

最新版の検証結果について、履歴用テストが旧仕様で失敗するのを不具合と誤認しないこと。実ブラウザ・スマートフォンの検品は別途行う。
