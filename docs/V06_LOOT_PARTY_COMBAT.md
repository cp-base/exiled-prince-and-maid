# v0.6 改修記録 — 戦利品・仲間編成・同時戦闘

更新日：2026-11-09

## 変更の目的
ユーザーの依頼①敵撃破時の装備ドロップ、②獲得した人材を遠征に参加できる仲間にする、③近接キャラが一緒に殴りに行き、遠距離キャラは後方で攻撃する戦闘方式を、既存v0.5の上へ実装する。

以下の装備、ドロップ率、戦闘能力、仲間人数などの数値は**試験用の仮仕様**。開発者側の提案であり、正式採用ではない。

## ① 遠征中のドロップ
- 敵撃破ごとに装備ドロップを抽選。通常敵28%、10体ごとのボスは確定ドロップ。
- 鉄の剣、狩人の弓、木の杖、短剣、古い槍の5種の元装備。装備種類ごとに近接・遠距離と攻撃間隔が異なる。
- 品質は通常／良品／希少で攻撃補正が変動。敵の到達深度に応じて小さく補正が上がる。
- ドロップは1個体ずつユニークなIDで所持品に記録。重複して別々のキャラへ装備可能。
- 戦闘中にドロップ速報、帰還後に戦利品一覧。帰還した時点で装備が所持品に移る（死亡しても持ち帰る）。
- v0.5の「噂」は限定装備の確定ドロップとして維持。通常抽選と両立。固定装備を所持品の先頭に表示し、過去のテストとの互換性を保つ。
- 倉庫制限・売却・分解・自動整理・本格的なランダム接辞は未実装。

## ② 仲間の加入と編成
- v0.4で非戦闘人材だった「旅の鍛冶見習い」を遠征参加可能な仲間へ変更。工房＋街道の発見条件、内政イベントの抽選は維持。
- 発見した時点で自動加入。王子とメイドを固定、鍛冶見習いは町で遠征参加・待機を切り替える。試作上限は3名。
- 仲間はHP・基礎攻撃・装備スロット・攻撃間隔を持ち、敵の攻撃対象になり、全員戦闘不能になった時点で遠征終了。
- 村長の娘はこれまでどおり重要人物として扱い、仲間にはしない。
- 一人分の仲間を追加する最小試作であり、汎用仲間生成や加入条件バリエーションは未実装。

## ③ 近接・遠距離の同時戦闘
- 前衛（近接）は敵の接近後、敵の目前まで移動して攻撃。複数の近接キャラが同時に前進し、独立したクールタイムでそれぞれ攻撃する。
- 後衛（遠距離）は後方から光弾の軌跡を表示して攻撃し、前進しない。
- 武器の種類によって役割が切り替わる。初期状態は王子が近接、メイドは遠距離、鍛冶見習いは近接。弓や杖なら遠距離、剣や槍なら近接。
- 敵の攻撃は生存する近接メンバーを優先し、複数前衛へ順番に分散。前衛がいなくなれば後衛を攻撃する。
- v0.5の第10戦突破時の村長の娘救出、親密度更新と重複防止を維持。

## 対応・改修した既存機能
- 内政選択→結果確認→装備・仲間の編成→出撃→戦闘→帰還のループを維持。
- `state.items` の既存ID方式を活用し、ドロップごとの装備定義を `itemData` に生成。現段階では独立ファイル化せず単一HTMLのまま。
- `state.people` に加入人物、`state.party` に出撃対象を記録。装備枠は `state.equipment` に保持。
- 一度の遠征で拾った装備は `battle.drops` にまとめ、`endRun` で所持品へ反映。
- `battle.timers` と `battle.positions` をキャラクター単位に変更し、近接移動と遠距離攻撃を表現。
