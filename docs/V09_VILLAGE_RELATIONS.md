# v0.9 改修記録 — 灰渡の重要人物と狩人トーマの討伐イベント

日付：2026-11-09 / 対象：単一HTML版 `index.html`。

## 要望と範囲
ユーザーが灰渡の**重要人物の友好度対象を「村長の娘・村長・狩人トーマ」の3人に限定**。旧TRPG案の「鍛冶師トーマ」は採用しない。狩人トーマの友好度・出来事フラグが村の討伐イベントにつながるようにする。最初の村はシンプルにし、住人ごとのターン自律シミュレーションは行わない。

## 実装
- 町の人物画面に、従来の村長の娘に加え **👴 村長** と **🏹 狩人トーマ** を表示。各人の信頼・友好度（0〜5）、現在の台詞、最近の履歴、トーマの討伐状況を表示。
- 村長：開始時に挨拶（信頼+1）。町の街道Lv2到達、工房Lv1到達、娘の救出、森の大狼討伐の各出来事で一度ずつ信頼が上がる。**本人を遠征仲間にはしない。**
- 狩人トーマ：初めて1遠征で3体以上倒して帰還したときに出会う（友好+1）。その後の別の遠征で5体以上倒して帰還すると「森の大狼の足跡」の情報（友好+1）。
- 手がかりを得ると、メイドの提案に「狩人トーマと森の魔物を討伐しましょう！」が出現。物語の進行を無用なランダム抽選で見失わないよう、**未達成の間は提案の優先枠**とする。従来の通常提案の抽選は継続。
- 討伐依頼を選んだ遠征の8体目を特別な敵「森の大狼」に変更。撃破すると討伐成功（トーマ友好+2、村長信頼+1）。帰還結果と人物履歴にも記録。一度きりの成功フラグ。8体目に届かなかった場合は未達成のまま次回再挑戦可能。
- **普段の遠征で8体以上倒しても討伐イベントは進行しない**。討伐依頼を選択した回だけ専用敵が出る。
- 村長の娘の救出時には村長がお礼を言い、信頼が上がる。恋愛・初回交流・10体目救出・帰還後のランダム交流・編成は従来どおり。
- 全員のフラグ・履歴は`state.relationships` に保持。町の重要人物の関係値以外に個別NPC自律行動は追加していない。
- 元からある「旅の鍛冶見習い」はv0.8のランダム獲得できる**遠征仲間の試作**として残している。重要人物の友好度画面には含めず、鍛冶師トーマは登場しない。
