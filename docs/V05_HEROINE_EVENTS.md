# v0.5 試作記録 — 村長の娘と親密度イベント

日付：2026-11-09 / 対象：`index.html`

## 追加したもの

- **村長の娘との出会い**：灰渡の開始時に短い出会いの場面を表示。遠征仲間ではなく町の重要人物として扱う。固有名はまだ付けていない。
- **親密度と履歴**：`state.relationships.daughter` に `met`, `rescued`, `affinity` (0〜5), `visits`, `flags`, `history` と現在の場面を保持。町の「灰渡の人々」に関係と最近の出来事を表示。
- **メイドの提案経由の交流**：町の提案「村長の娘さんに会いに行きましょう！」を選ぶと交流し親密度が上がる。v0.4どおり、この選択は遠征前の内政1回分を使用する。
- **偶然の遭遇**：町の他の選択時に28%（仮）で、まだ発生していない市場・街道・差し入れの交流イベントが発生。住人個別の毎ターン自律行動は計算しない。
- **遠征10体目の救出**：10体目の敵を倒したあと、一度限りで村長の娘の救出が発生。短時間だけ娘のスプライトとメッセージを表示し、帰還結果にも残す。救出前の親密度によって娘の台詞が分岐。
- **救出後のお礼**：次の町の提案に「村長の娘さんから、お礼のお誘いです！」が一度だけ出現し、交流後は通常の訪問提案に戻る。
- **将来のためのフラグ**：`meeting`、`rescue`、`thanks`、`chance_*` を記録。今後の周回へ保持する仕組みはまだ実装しない。

## 既存の v0.4 を維持

- 内政を一つ選んだあと結果を見る→装備を整えて出撃、という分離された流れ。
- 二人の横スクロール自動戦闘、噂からの装備発見、装備の付け替え。
- 街道・工房の育成とランダムな技術品／町の人材発見。
- 灰渡の仮目標（街道Lv3・工房Lv2・一度の遠征で敵10体）。
- 町の住民ごとの自律行動計算や資源収支の計算は追加していない。
