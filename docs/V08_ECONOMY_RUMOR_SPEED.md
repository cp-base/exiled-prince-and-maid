# v0.8 改修記録：噂・ドロップ経済・行商人・試走4倍速

更新：2026-11-09

## 背景と依頼
ユーザーがv0.7を実機プレイし、10体撃破が楽になったことを確認。次の改修として、(1) 噂による確定装備を廃止して「話を聞くだけ」にする、(2) 装備が落ちすぎるため確率を下げ、お金と仮の共通素材をドロップさせる、(3) 商人を町に呼べるようにする、(4) 試走用の4倍速切り替えを追加する、という指示を受けた。

実装された数値や商品は**試験用の仮仕様**であり正式決定ではない。今までのイベント・仲間・町の育成は維持する。

## 変更した仕組み

### 1. 噂は情報のみ
- 「うわさ話を聞いてみましょう！」を内政の提案プールに追加。提案は従来どおり最大3つをランダム提示する（v0.7の初回交流の強制提示は維持）。
- 街道Lvに応じて候補が増える短い地域情報7件を用意。
- 同じ噂の重複を避けつつ、全件既読のときには再度抽選可能。
- 噂による武器の確定ドロップ・旧武器3件の固定配布を廃止。情報以外の効果なし。
- 技術品「古い道案内の図」は、噂に関連した旧固定ドロップ条件の変更から**素材ドロップ率+10%**へ効果を一時変更。

### 2. 低頻度の装備と、普通の戦利品
- 装備ドロップ：通常敵 **28%→7%**、10戦ごとのボス **確定→25%**（すべて仮値）。
- 武器ベース5種・品質3種（v0.6）や個別アイテムID、装備・編成は変更しない。
- 敵撃破ごとに所持金 **1〜3G**、ボスは追加 **+2G**。
- 共通素材は通常 **40%**（案内の図があれば50%）で1個、ボスは追加1個の素材確定。
- 遠征中の獲得数を速報表示し、帰還時にGold/素材/武器を倉庫へ反映する。
- 戦闘不能になって帰還した場合も獲得分を持ち帰る（旧版の装備と同様）。

### 3. 行商人を呼ぶ
- 町画面に「行商人を呼ぶ」を追加。今回は手数料・条件なしで呼べる。
- 来訪後は出撃まで滞在。次の遠征に出るといったん帰り、また呼べる。
- 仮の品揃えは鉄剣（近接、攻撃+2）と短弓（遠距離、攻撃+2）、それぞれ **10G**。
- 共通素材1個を **2G** で売却できる。残高不足・素材不足での取引はできない。
- 買った武器も既存の所持品に個別追加し、王子・メイド・仲間へ装備可能。
- 交易を本格的な需給・生産シミュレーションにはしない。

### 4. 4倍速
- 画面上部のステージ下欄に「速度：1倍」ボタンを追加。タップで1倍 ↔ 4倍を切替。
- 速度の対象は自動戦闘の時間進行。内政の選択肢や画面上の操作は速くならない。
- 高速時も最大0.045秒相当の小さな処理単位へ分割し、攻撃クールタイムやイベント判定を飛ばしにくくしている。
- 村長の娘救出モーダル中は従来どおり戦闘が停止する。4倍速設定でもポップアップの確認は必要。
- 速度は現在のページを開いている間保持し、再読み込みで1倍に戻る。
