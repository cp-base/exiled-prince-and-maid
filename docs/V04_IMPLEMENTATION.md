# v0.4 改修記録 — 内政の選択とランダムな発見

日付：2026-11-08 / 対象：単一HTML版 `index.html`

## 目的と範囲
会話で合意した方向性は「町の内政にプレイヤーの選択とランダムな発見の二層を用意する」「能力の直接強化より装備を中心にする」。ここでは v0.3 の遠征・装備・仮目標を維持し、内政のプレイ体験だけを小さく検証する。以下の数値や具体イベントは**実装者による仮置き**であり、正式仕様として確定したものではない。

## 実装した5項目
1. **内政提案に差し替え**：王子の稽古・メイドの稽古・弁当の直接ステータス強化を削除。街道整備、工房復興、町での聞き込み、装備の噂の調査、内政なしの出撃準備を選べる。
2. **街道・工房の効果を変更**：街道Lv1で森の噂、Lv2で古い道の噂が解放（最長撃破数条件も併用）。工房Lvが装備品の攻撃補正に加算される。**装備なしでは攻撃が増えず、王子やメイドの素のHP・攻撃力は変わらない**。
3. **内政時のランダムイベント**：街道・工房の選択後に38%、聞き込み選択後に65%の確率で条件に合った発見物を抽選。対象が無い場合や抽選に外れた場合は「発見なし」。イベント内容を都度AI生成しない。
4. **装備以外の発見物と人材**：町の発見物は別画面に蓄積し、毎ターン住民の行動計算はしない。
   - 技術品「工房の手入れ帳」：装備の攻撃補正+1。工房Lv1以上が候補条件。
   - 技術品「古い道案内の図」：噂の探索で必要な敵撃破数-1。街道Lv1以上が候補条件。
   - 町の人材「旅の鍛冶見習い」：装備の攻撃補正+1。工房Lv1かつ街道Lv1以上が候補条件。**遠征仲間ではない**。
   - 発見物は同一IDを重複獲得しない。初期町向けの試験用の3件に限定。
5. **出撃を分離**：内政の提案を1つ選んで結果を確認し、その後装備を変更できる。独立した「装備を確認して出撃する」ボタンで遠征開始。1遠征につき内政の選択は1回まで（仮ルール）。内政なしで遠征することもできる。

## 維持したもの
- 王子・メイド二人の横スクロール自動戦闘、連続戦闘、二人が倒れた後の帰還。
- 既存装備3種類と、噂を選んで所定の敵数に到達する発見方式（ドロップランダム生成は未導入）。
- 街道Lv3・工房Lv2・10体撃破の灰渡目標は**引き続き試作の仮目標**。
- 生産・消費の収支計算、住民ごとの自律行動はなし。リロード後は初期化。

## 実装メモ
- `state.items` は遠征用装備、`state.finds` は技術品、`state.people` は町の人材。
- `planning` を内政選択済・未出撃の状態として保持。結果が見えた後に再選択できない。
- `townFindData` が発見候補・重み・表示情報、`rollTownFind` が当たり判定と獲得を担当。
- `requiredKills` が技術品「古い道案内の図」を反映。
- `equipmentBonus` に工房・技術品・人材の効果を集約。
- 将来データを増やしやすいよう役割を分離したが、v0.4は単一HTMLを維持。
